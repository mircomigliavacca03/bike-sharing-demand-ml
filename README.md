# Bike Sharing Demand Prediction (Machine Learning in R)

## Project Overview
Progetto di Machine Learning ed Econometria applicata volto alla previsione della domanda oraria di bike sharing. L'analisi implementa modelli basati su alberi decisionali seguendo l'approccio accademico di *An Introduction to Statistical Learning with Applications in R (ISLR2)*.

## Tech Stack & Packages
* **Language:** R
* **Libraries:** `randomForest`, `tree`, `caret`, `ggplot2`, `corrplot`, `pdp`, `readxl`

## Methodology
1. **Exploratory Data Analysis (EDA):** Analisi delle correlazioni tra condizioni meteorologiche, stagionalità e volume della domanda.
2. **Feature Engineering & Preprocessing:** Gestione di variabili temporali e categoriche.
3. **Model Training & Comparison:** Implementazione e confronto delle performance tra Regression Trees, Random Forest e modelli parametrici.
4. **Interpretation:** Visualizzazione tramite Partial Dependence Plots (PDP) e Feature Importance.
